# Protocol Stack Quest
Ссылка - https://lulema22.github.io/information-theory-1/

**Protocol Stack Quest** — это интерактивный HTML-сайт для объяснения темы **«Стек протоколов»** в компьютерных сетях.

Проект сделан как творческое задание: пользователь не просто читает теорию, а взаимодействует с сайтом, собирает стек протоколов под разные сетевые сценарии, смотрит визуализацию передачи пакета и проходит небольшой тест.

---

## Цель проекта

Цель сайта — показать, что интернет работает не за счет одного протокола, а за счет набора протоколов, распределенных по уровням.

Сайт объясняет:

- что такое стек протоколов;
- зачем нужны уровни в сетевой модели;
- чем отличаются прикладной, транспортный, межсетевой и канальный уровни;
- почему разные задачи требуют разных протоколов;
- как данные проходят через уровни при передаче по сети.

---

## Основная идея

Стек протоколов можно представить как многоуровневую систему.

Каждый уровень выполняет свою задачу:

1. **Прикладной уровень**  
   Отвечает за смысл сообщения и работу приложений.  
   Примеры: HTTP(S), DNS, SMTP, FTP, SSH, MQTT.

2. **Транспортный уровень**  
   Отвечает за передачу данных между процессами.  
   Примеры: TCP и UDP.

3. **Межсетевой уровень**  
   Отвечает за адресацию и маршрутизацию пакетов между сетями.  
   Примеры: IP и ICMP.

4. **Канальный уровень**  
   Отвечает за передачу данных внутри конкретной среды.  
   Примеры: Wi-Fi, Ethernet, LTE, 5G.

В игре канальный уровень специально сделан постоянным и не выбирается пользователем, потому что он показывает заменяемую среду передачи данных.

## Что есть на сайте

### 1. Теоретический блок

В начале сайта объясняется, что такое стек протоколов и почему интернет нельзя свести к одному протоколу.

Также показана структура уровней:

- прикладной уровень;
- транспортный уровень;
- межсетевой уровень;
- канальный уровень.

---

### 2. Мини-игра «Собери стек под задачу»

Пользователь выбирает один из сетевых сценариев, например:

- открыть веб-сайт;
- узнать IP-адрес по имени сайта;
- отправить email;
- совершить видеозвонок;
- отправить сообщение от умного датчика.

Для каждого сценария нужно выбрать:

- прикладной протокол;
- транспортный протокол;
- межсетевой протокол.

Канальный уровень в игре не выбирается, потому что среда передачи может быть разной: Wi-Fi, Ethernet, LTE или 5G.

Если пользователь выбирает неправильный стек, появляется короткое сообщение:

> Пока не совпало.

Если стек выбран правильно, сайт показывает объяснение.

---

### 3. Визуализация инкапсуляции

На сайте есть интерактивная демонстрация того, как сообщение превращается в пакет.

При нажатии на кнопку показывается, как данные проходят через уровни:

1. данные приложения;
2. TCP-заголовок;
3. IP-заголовок;
4. кадр Wi-Fi или Ethernet.

Эта часть помогает понять принцип инкапсуляции: каждый уровень добавляет свою служебную информацию.

---

### 4. Реальные примеры из ИТ-индустрии

Отдельный блок показывает, где стек протоколов используется в реальной жизни:

- финтех и онлайн-банкинг;
- облачные сервисы;
- игры и стриминг;
- кибербезопасность;
- интернет вещей.

Этот раздел показывает, что стек протоколов — это не только теория, а реальный инженерный принцип.

---

### 5. Тест для проверки понимания

В конце сайта есть тест из нескольких вопросов.

В тесте показывается:

- номер текущего вопроса;
- общее количество вопросов;
- количество набранных баллов.

Если пользователь правильно отвечает на все вопросы, тест завершается сообщением:

> Молодец, все верно!

Если есть ошибки, появляется сообщение:

> Не все верно, попробуй снова.

После завершения теста появляется кнопка **«Пройти снова»**.  
При повторном прохождении тест начинается заново, а баллы сбрасываются до 0.
